# Zomato Data Analysis

## 📌 Overview
Exploratory Data Analysis (EDA) on the Zomato restaurant dataset to understand customer ratings, restaurant types, cost preferences, and ordering behavior.

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

## 📊 Key Analysis
- Data cleaning & rating conversion
- Restaurant type distribution
- Rating distribution analysis
- Cost analysis for two people
- Online vs Offline order comparison
- Heatmap visualization

## 🔍 Key Insights
- Majority restaurants fall under dining category.
- Most ratings range between 3.5 and 4.0.
- Online orders tend to receive slightly higher ratings.
- ₹300 is the most preferred spending range for couples.
